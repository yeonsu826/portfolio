# ChapChew

> 씹는 움직임으로 왁뿌볼을 쪼개는 얼굴인식 인터랙티브 게임

전면 카메라로 얼굴과 입 움직임을 인식하고, 씹을 때마다 왁뿌볼의 표면이 눌리고 갈라지도록 연결한 Unity 프로젝트입니다.

처음에는 사용자의 얼굴 움직임을 캐릭터가 따라 하는 방식이었습니다. 현재는 사용자의 움직임으로 공의 변화를 만들어 내는 놀이에 집중합니다. 고양이는 화면 속 동반자로 남고, 주요 피드백은 왁뿌볼이 담당합니다.

## 플레이 흐름

1. 시작 화면에서 놀이를 시작합니다.
2. 한입당 씹기 목표를 정합니다.
3. 얼굴 위치, 한입 동작, 씹기 기준을 개인에 맞게 측정합니다.
4. 인식된 씹기 동작에 따라 왁뿌볼이 눌리고 균열이 드러납니다.
5. 새로운 한입에는 공을 초기화하고 놀이를 이어갑니다.
6. 완료 후 한입별 씹기 기록, 목표선과 그래프, 초반과 후반의 흐름 요약을 확인합니다.

## 구현

- Unity · AR Foundation · C#
- 개인별 움직임 기준 측정과 얼굴 추적
- 씹기 이벤트에 연결한 왁뿌볼 표면 변형과 균열 표현
- 한입 이벤트에 따른 공 초기화
- 한입별 카운트 기록과 리포트

왁뿌볼의 갈라짐은 미리 나눈 표면 조각과 변형으로 표현합니다. 실시간 물리 파괴가 아닌 시각적 반응입니다.
