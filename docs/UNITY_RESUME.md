# 패러블 Unity 개발자 지원용 이력서

- 독립 경로: /#/resume/unity (개발 서버의 base 포함)
- 현재 미리보기: http://localhost:5180/portfolio/#/resume/unity
- 서버가 꺼졌다면 프로젝트에서 npm run dev -- --host 127.0.0.1 실행 후 표시된 주소에 /portfolio/#/resume/unity 추가
- 기존 화면 수정·배포·커밋·푸시 없이 독립 lazy route 추가. 보류된 스토리 작업은 이번 변경 대상이 아님.

## 편집과 저장
문구 편집 → 점선 영역 수정 → 편집 마치기 → 브라우저 저장.
브라우저 저장은 해당 주소/브라우저에만 유지됨. 다른 기기로 옮기거나 보관하려면 파일 백업(JSON) 후 파일 복원.
복원 후 브라우저 저장을 눌러야 재접속 시 유지됨. React 문자열로 출력하며 복원 파일의 필수 키·문자열 타입·길이를 검사함.
이름·연락처·소개·업무·프로젝트 본문·기술·학력·교육·자격증을 편집할 수 있음. 고정 항목명/링크 주소/프로젝트 기간은 UnityResume.tsx에서 수정.
문구를 크게 늘리면 페이지가 늘어날 수 있으므로 A4 화면 확인 및 실제 인쇄 미리보기로 재검토.

## PDF 저장
일반 Chrome/Edge에서 로컬 주소 열기 → 인쇄 / PDF 또는 Ctrl+P → PDF로 저장.
용지 A4 / 세로 / 배율 100% / 여백 없음 / 머리글 및 바닥글 해제. 모눈까지 출력하려면 배경 그래픽 선택.
현재 원고는 2장 기준. 저장 전 미리보기에서 2장인지 확인. 링크는 실제 a 요소로 작성되어 브라우저 PDF에서 클릭 가능하도록 구성.
내장 브라우저는 window.print 호출에 응답하지 않아 일반 브라우저 사용 권장.
실제 PDF 생성·페이지 수·PDF 링크 클릭 검증은 미완료. A4 화면 확인은 출력 레이아웃 검토 도구이며 실제 PDF를 대신하지 않음.

## 자료 및 검증 범위
사용자 최신 확인, C:/WorkSpace/해외취업/경험_역량_기초자료.md(2026.11.10), 기존 Contact.tsx 공개 이메일/GitHub, GraceSeaCaseStudy.tsx 공개 소개·기술·스토어 링크, portfolio.ts 콘텐츠 확인.
React/Vite/HashRouter 관례 사용. 새 의존성 없음. npm run build 성공.
390px 모바일 화면, 한글 줄바꿈, 가로 넘침 없음, 편집·저장·새로고침 복원 확인.
A4 화면 두 장: 각 793.69×1122.52px. 본문 마지막 지점 943.69/971.25px, 푸터 시작1060.73px로 겹침 없음. 제목·본문은 break-inside/break-after로 분리 방지.
링크 href 확인. 외부 링크 전체 도착 페이지나 앱 내부 코드/회사 원본 Unity 프로젝트/성능 측정은 검증하지 않음.
레퍼런스 URL 직접 접근 실패. 사용자 제공 특징으로 독자적인 기하학 장식·편집 레이아웃 구현.

## 제출 전 확인할 사실
- 버추얼 아이돌: 역할·기술·기간·결과 근거 없음 → 본문 제외. 보완 시 추가 가능.
- 태안 레이싱: 모션 연동·게임 로직·맵 구성 중 직접 담당한 세부 범위.
- 괴산 기간과 퇴사 후 계약 관계, 양주 기간·세부 역할. 이력서에는 확인된 참여 사실만 기재.
- 금산 사용 API 명칭과 구체 오류 대응·안정화 사례. 언어 수·처리 속도·실시간 처리는 기재하지 않음.
- 은혜의 바다 출시일·공간 운영 시작일·3D 공간 엔진은 미확인 → 제외. 앱 기술은 공개 포트폴리오 설명 기준이며 원본 앱 코드 검증 아님.
- 교육기관은 미확인 → 생략. 증빙 기준 회사 경력·학력·교육·자격증 명칭 최종 확인.
- 실시간 멀티플레이 동기화·애니메이션/카메라 시스템 상세 경험은 확인되지 않아 주장하지 않음.
